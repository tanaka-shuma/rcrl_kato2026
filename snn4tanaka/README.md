# spnet — モジュラースパイキングニューラルネットワーク シミュレータ

French型LIFニューロン・短期可塑性(STP)・モジュラー結合構造を持つスパイキングニューラルネットワークのシミュレータです．
計算コアは Cython (Pure Python mode) で書かれた `simu.py` で，コンパイルして C拡張モジュールとして実行します．
Cythonは通常のPython構文に型情報などを付加してC言語にコンパイルすることで実行速度を高速化する仕組みで，
Pure Python modeでは `.pyx` ファイルを使わず，`.py` ファイルのまま型アノテーション（`cython.int` など）を書くことで純粋なPythonとしても動作させられます．
ただし，コンパイルせず素のPythonとして実行した場合はCython版の高速化が一切効かないため，実行速度はかなり遅くなります．

作成: H. Kato (Oita Univ., Japan)

## 動作確認環境

- Ubuntu 24.04.4 LTS
- Python 3.12
- gcc 13.3.0
- Cython 3.1.4 / numpy 2.1.2 / networkx 3.4.1

## セットアップ

### Cython拡張のビルド

`simu.py` はソースのままでは実行できません．`setup.py` / `makefile` を使ってCコンパイルし，`simu.cpython-*.so` を生成する必要があります．

```bash
make comp
```

内部では `python3 setup.py build_ext -i` が実行され，`simu.c` / `simu.html`（Cythonのアノテーションレポート）/ `simu.cpython-*.so` がこのディレクトリ直下に生成されます．

`simu.py` を編集した場合は，再度 `make comp` を実行してビルドし直してください．

### ビルド成果物の削除

```bash
make clean       # simu.c と build/ のみ削除
make clean_all    # 上記に加え，*.so, *.html, __pycache__ なども削除
```

## 実行方法

ビルド後，エントリーポイントの `spnet.py` を実行します．

```bash
python3 spnet.py [オプション...]
```

例: モジュール2×2，シミュレーション時間500秒，スパイクデータを出力

```bash
python3 spnet.py -c 2 -r 2 -T 500 -spk
```

## コマンドラインオプション一覧

| オプション | 説明 | デフォルト |
| --- | --- | --- |
| `-seed` | 乱数シード | `1` |
| `-T` | シミュレーション時間 [s] | `1000` |
| `-dt` | シミュレーションの時間分解能 [ms] | `0.2` |
| `-Ne` | 興奮性(RS)ニューロン数 | `800` |
| `-Ni` | 抑制性(FS)ニューロン数 | `200` |
| `-c` | モジュール格子の列数 | `1` |
| `-r` | モジュール格子の行数 | `1` |
| `-Minter` | モジュール間の結合軸索数 | `2.0` |
| `-Sinter` | モジュール間結合数のSD | `0.0` |
| `-g_ee` | モジュール内 E→E シナプス強度(速い成分) | `5e-6` |
| `-g_ei` | モジュール内 E→I シナプス強度(速い成分) | `5e-6` |
| `-g_ie` | モジュール内 I→E シナプス強度(速い成分) | `2e-5` |
| `-g_ii` | モジュール内 I→I シナプス強度(速い成分) | `1.5e-5` |
| `-g_inter` | モジュール間 E→E シナプス強度(速い成分) | `0` |
| `-g_ee_slow` | モジュール内 E→E シナプス強度(遅い成分) | `0` |
| `-g_ei_slow` | モジュール内 E→I シナプス強度(遅い成分) | `0` |
| `-g_ie_slow` | モジュール内 I→E シナプス強度(遅い成分) | `0` |
| `-g_ii_slow` | モジュール内 I→I シナプス強度(遅い成分) | `0` |
| `-g_slow_inter` | モジュール間 E→E シナプス強度(遅い成分) | `0` |
| `-spk` | スパイクデータをファイル出力する(フラグ) | オフ |
| `-idx` | 指定したニューロン番号の内部状態を標準出力へ逐次出力 | オフ |

上記以外にも `gk` / `Cstep` / `tca`（Caイオン依存Kアダプテーション）や `U` / `tau_f` / `tau_d`（STPパラメータ）が `option/option.py` の `get_opts()` 内にデフォルト値として定義されていますが，確定値として運用しているためコマンドラインからは変更できません．値を変えたい場合は `option/option.py` の `parms` 辞書を直接編集してください．

## 出力ファイル

`-spk` を指定した場合，シミュレーション中に以下の形式のファイルがカレントディレクトリに追記で出力されます（ファイル名にパラメータ値が埋め込まれます）．

```
spkN<総ニューロン数>Mcol<列数>Mrow<行数>Gee<...>...Seed<シード>.dat
```

各行: `time(s) neuron_index module_local_index module_index`

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `simu.py` | シミュレーション本体（ニューロン・シナプス・STP・モジュラーネットワークの各クラスと `simu()`）．Cython (Pure Python mode) で記述 |
| `option/option.py` | コマンドラインオプションの定義とデフォルトパラメータ |
| `spnet.py` | エントリーポイントスクリプト（`simu()` を呼び出すだけ） |
| `setup.py` / `makefile` | Cython拡張のビルド設定 |

## 注意: 結合強度パラメータについて

`-g_ee` などのオプションで指定する結合強度の値は，STPの初期化処理（`simu.py` の `STP.__init__` 内 `g /= U`）によって内部的には `g / U` として保持されます．
つまり，コマンドラインで与えた値を `g`，STPのUtilization係数を `U` とすると，内部的な結合強度は `g/U` であり，逆に言えば「内部的な結合強度 × U」がオプションで指定した値に対応します．
